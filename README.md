# Mixxx mapping for the Numark Mixtrack Platinum FX

Based on the work of [QGazQ](https://github.com/qgazq/mixxx_numark_mixtrack_platinum_fx).
The original mapping is currently saved in the [original folder](./original/) for reverse ingeneering purpose, but will be deleted when the remapping will be fully written.

## Installation

Download the required files and place them directly inside your [Mixxx controllers directory](https://manual.mixxx.org/2.4/fr/chapters/controlling_mixxx#installing-a-mapping-from-the-forum), and voila ! That's all.

### Required files

- [The midi mapping](./Numark%20Mixtrack%20Platinum%20FX.xml)
- [The scripting](./Numark-Mixtrack-Platinum-FX-scripts.js)

Soon I'll auto-publish a .zip archive to make this process even easier for you !

## Configuration

You can view the configuration under the `CONFIG` key of the script.
All the configurations and behaviors are described directly there.

## Developpement

Please be aware that this project does not follow [Mixxx's mapping contributing guidelines](https://github.com/mixxxdj/mixxx/wiki/Contributing-Mappings), but is fully tested and works on the software.

### Typing files

Typing files are in the [types directory](./types), and are originally downloaded from the [Mixxx's source code](https://github.com/search?q=repo%3Amixxxdj%2Fmixxx+path%3Ares%2F**%2F*.d.ts&type=code).
An additionnal [mpfx](./types/mpfx/) folder contains the types (components, utilities, ...) for this controller mapping.

### Documentation

The [docs](./docs/) folder contains some documentation on how the controller works (bytes values, etc...).
It has been fully generated by Claude Code based on the [original mapping](./original/).
